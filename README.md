# Trabajos_variados

Repositorio que recopila diversos proyectos y ejercicios realizados durante mi formación académica y en mi tiempo libre. No son proyectos desplegados, sino una muestra del código que he ido escribiendo en distintas ocasiones.

## Estructura del repositorio

### DAW (Desarrollo de Aplicaciones Web)

| Proyecto | Descripción | Tecnologías |
|----------|-------------|-------------|
| **Ejercicio_mail** | Ejercicio de envío de correos electrónicos con plantillas HTML | PHP, PHPMailer |
| **GesELECTRERA** | Gestor de estaciones de recarga eléctrica | Java |
| **Practica_movilidad** | Práctica de movilidad con formularios y validación | PHP, HTML, CSS |
| **Reserva_mesa** | Sistema de reservas de mesas en restaurante con plano interactivo | PHP, HTML, CSS, MySQL |
| **Tienda_jabones** | Tienda online de jabones artesanales con panel de administración | PHP, HTML, CSS, MySQL, FPDF |
