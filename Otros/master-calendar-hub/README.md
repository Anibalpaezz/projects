# Master Calendar Hub

Aplicación de calendario multi-usuario con autenticación y gestión de eventos.

## Tecnologías

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (autenticación y base de datos)
- i18next (internacionalización)

## Funcionalidades

- Gestión de calendarios personales
- Creación y edición de eventos
- Vista de calendario con navegación por semanas/días
- Autenticación de usuarios
- Soporte multi-idioma (español/inglés)
